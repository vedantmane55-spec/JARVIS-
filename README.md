# Vedyya Drop

A standalone top-down solo battle royale for touchscreens and keyboards. Download `index.html` and open it in a browser. Enter a guest callsign, then choose Start match.

Drag the left pad to move and hold FIRE to target the closest rival in range. Keyboard controls are WASD or arrow keys and Space. Survive against 11 bots, collect medkits and stay inside the shrinking ring. Wins and best KOs are saved locally when browser storage is available.
